# Scholar's Wyvern

A personal library of games, food, books and crafts, guarded by Quill the wyvern.

Built step by step with Claude, as a live project for learning how to make and run a website.

## What's here

| Path | What it is |
|---|---|
| `index.html` | Home page |
| `dnd/` | The D&D shelf: landing page and class guides |
| `css/styles.css` | The shared stylesheet: colours, fonts, header, footer. One change here updates every page. |
| `images/` | Quill, the logos, favicons and guide art (web-sized copies; originals are kept elsewhere) |
| `CLAUDE.md` | Instructions for Claude when it works on this repo |

## How it's published

Plain HTML and CSS, with no build step: what's in this repo is exactly what visitors get. It's published with GitHub Pages.
